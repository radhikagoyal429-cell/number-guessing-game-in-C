 
# Number Guessing Game in C

A simple C program where computer generates a random number between 1-100 and user has to guess it.

This project demonstrates how binary logic (0 and 1) works in decision making - if guess > num (0) / if guess < num (0) / if guess == num (1).

### How to Run
gcc project_1_number_guessing_game.c -o game
./game

### Features
- Uses srand() and rand() for random number generation
- Counts total guesses
- Gives hints (higher / lower)
